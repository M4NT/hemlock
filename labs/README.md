# Hemlock Labs

Interactive notebooks for exploring RAG security scenarios.

| Notebook | Description |
|----------|-------------|
| `01_attack_walkthrough.ipynb` | End-to-end walkthrough of a direct injection attack with trace visualization |
| `02_defense_comparison.ipynb` | Compare rule-based vs LLM-based defenses side by side |
| `03_fuzzer_demo.ipynb` | Adaptive fuzzer finding variants that bypass a specific defense |
| `04_scorer_analysis.ipynb` | Full scoring matrix with charts by attack type and hardening level |

> Notebooks coming soon. Track progress at the [main repo](https://github.com/M4NT/hemlock).
